# 0 與 1 的藝術：資料表示與處理

國中九年級資訊科技互動教材網站。透過二進位、文字、聲音與影像四個單元，帶學生理解現實世界的資訊如何轉換成可儲存、處理與傳遞的數位資料。

網站已部署於 [GitHub Pages](https://byte-core-su.github.io/unforte_114/)。

## 網站架構

```text
unforte_114/
├── index.html                 # 首頁：課程地圖與學習路徑
├── 1.html                     # 單元一：二進位原理
├── 2.html                     # 單元二：文字數位化
├── 3.html                     # 單元三：音訊數位化
├── 4.html                     # 單元四：影像數位化
├── course-data.js             # 集中管理單元資料、目標、卡片、檢核與討論題
├── course-core.js             # 產生共用導覽、首頁卡片、學習路徑與課後區塊
├── course-components.css      # 共用元件樣式
├── images/                    # 教材圖片與互動所需圖像
├── tests/check-course.ps1     # 自動結構／互動冒煙檢查
└── TESTING.md                 # 人工互動回歸檢查清單
```

這是一個純靜態網站，直接由 GitHub Pages 發布。頁面使用 Tailwind CDN，不需要安裝套件或建置流程。

## 課程內容與互動

| 單元 | 主題 | 核心概念 | 主要互動 |
| --- | --- | --- | --- |
| 1 | 二進位原理 | 位元、權值、十進位與二進位轉換 | 二進位熱身、BINARY BONANZA 5×5 挑戰、雙向換算測驗 |
| 2 | 文字數位化 | 摩斯密碼、共同編碼、ASCII／Big-5／Unicode | 聽音解碼、發報驗證、鍵盤空白鍵發報、SOS 示範 |
| 3 | 音訊數位化 | 振幅、頻率、取樣、量化、聲音格式 | 波形觀察、取樣量化模擬、WAV／MP3／MIDI 比較 |
| 4 | 影像數位化 | 像素、解析度、色彩量化、壓縮與格式 | 像素探索、自由取樣、8×8 量化格、愛心／笑臉／火箭參考圖案 |

每個單元都包含：

- 學習目標與建議學習順序
- 可返回「課程地圖」的單元導覽
- 重新開始後的下一步操作提示
- 三題課後快速檢核與徽章
- 一題雙人討論情境題

## 共用設定與維護方式

後續調整時，優先修改集中設定，避免在多個 HTML 頁面重複更動。

| 要調整的內容 | 優先修改檔案 |
| --- | --- |
| 單元名稱、主色、首頁卡片、學習目標、課後檢核、討論題 | `course-data.js` |
| 單元導覽、首頁課程卡、首頁學習路徑、課後共用區塊 | `course-core.js` |
| 學習目標、課後檢核與討論區的共用外觀 | `course-components.css` |
| 各單元專屬教材與互動 | 對應的 `1.html`～`4.html` |
| 圖片、照片與教學截圖 | `images/` |

各單元 HTML 仍保留靜態內容與基本互動備援；即使共用腳本未成功載入，學生仍能閱讀主要內容並操作基本檢核。

## 無障礙與替代操作

- 單元一的 BINARY BONANZA 可用 Tab、Enter 或空白鍵逐格選取。
- 單元二的發報鍵可用 Tab 聚焦後，以短按／長按空白鍵輸入點與劃。
- 單元四的色票與 8×8 量化格可用鍵盤操作；Enter 或空白鍵可上色。
- 重要互動回饋使用即時訊息，方便螢幕閱讀器取得結果。

## 測試

每次修改後，先執行自動檢查：

```powershell
powershell -ExecutionPolicy Bypass -File tests/check-course.ps1
```

這個檢查會確認集中設定、共用元件、主要互動程式碼、鍵盤操作與備援內容是否仍存在。完整的瀏覽器人工檢查步驟請見 [TESTING.md](TESTING.md)。

## 部署

1. 將變更提交並推送到 `main` 分支。
2. GitHub Pages 會自動發布靜態檔案。
3. 約等待一分鐘後，從 [公開網站](https://byte-core-su.github.io/unforte_114/) 確認更新。
